# GoatCounter Analytics — Setup Guide

## Step 1 — Create your free account
1. Go to → https://www.goatcounter.com
2. Click **"Sign up"**
3. For **"Site code"** type: `senaorucu`
   → your dashboard will be at: https://senaorucu.goatcounter.com
4. Enter your email + password → Create account
5. Confirm your email

## Step 2 — Upload the updated HTML files to GitHub
The tracking script is already added to all 3 pages:
- index.html ✓
- projects.html ✓
- about.html ✓

Just replace them in your GitHub repo. That's it — no other changes needed!

## Step 3 — View your analytics
Go to → https://senaorucu.goatcounter.com

You'll see:
- 📈 Pageviews over time
- 🌍 Visitor countries
- 📱 Device types (mobile / desktop)
- 🔗 Referrers (how people found you — LinkedIn, Google, direct)
- 📄 Which pages get the most visits

## ⚠️ Important
If the site code `senaorucu` is already taken on GoatCounter,
choose another code (e.g. `sena-orucu` or `senaorucu-portfolio`)
and update the script in all 3 HTML files:

Change this line:
  data-goatcounter="https://senaorucu.goatcounter.com/count"

To whatever code you chose:
  data-goatcounter="https://YOUR-CODE.goatcounter.com/count"

## ✅ That's it!
No cookie banner needed. No GDPR issues. 
Visitors are tracked anonymously — fully privacy-friendly.
